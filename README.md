# 💰 Finance Tracker

A simple finance tracking web application built using **HTML, CSS, JavaScript, and Firebase**.

## Features

- Add income and expense transactions
- Record bills
- Track total balance, income, and expenses
- Store data securely using Firebase
- Responsive and easy-to-use interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase
