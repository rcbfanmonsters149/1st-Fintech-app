# Minor spend tracker project


A simple expense tracking application built as a minor project to help users monitor and manage their daily expenses. The application allows users to manually add income and expense transactions, automatically categorises them based on their type, and provides a clear overview of spending patterns.

## Features

* Add income and expense transactions manually.
* Categorise transactions for better expense management.
* View a complete transaction history.
* Track spending across different categories.
* Simple and user-friendly interface.

## Purpose

The primary objective of this project is to provide an easy way for users to record their financial transactions and analyse where their money is being spent. It also serves as a learning project for implementing data management, and frontend/backend integration.
